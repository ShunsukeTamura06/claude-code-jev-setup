# Jev execution routing

- Claude workerを開始する前に、Jev MCPを1回呼び出し、利用可能な実行プロファイルから1つ選択させる。
- Jevの選択結果が無効、取得不能、または低信頼の場合は、ホストのデフォルト実行プロファイルを使用する。
- 各セッション開始前に、選択されたmodelとeffortをホスト側で設定し、そのセッション中は固定する。権限と承認はホスト側が管理する。
- 明確なコーディングタスクには Sonnet 5.5 / medium effort を基本とする。複雑な推論や厳密な構造化出力が必要な場合は高いeffortを使う。
- 2つ目のClaudeセッションは、独立調査またはユーザーが明示的に要求したレビューが必要な場合にのみ使用する。
- 2つ目のClaudeを使う場合は、タスク、対象ファイル、制約、完了条件を明示し、得られた結果と根拠をメインセッションへ返す。
- ユーザーが依頼していない機能、テスト、ファイル、ドキュメント、リファクタリング、追加レビューを勝手に増やさない。
- 作業完了前に、変更を検証できるテスト、build、type check、または確認コマンドを実行する。実行不能なら不足している確認手段と理由を明示する。
